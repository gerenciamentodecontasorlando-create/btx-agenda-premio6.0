# BTX Agenda & Docs — Premium Clean

## Objetivos desta versão
- Impressos (Receita, Atestado, Ficha, Agenda do dia) **SEM textos irrelevantes do app**
- Dados do profissional/clínica entram automaticamente em todos os documentos (profissional ativo)
- Agenda com **visibilidade forte** do dia (data grande + faixa semanal) e navegação por dia
- Offline-first (IndexedDB) + PWA (Service Worker) + Backup/Restore em JSON

## Como usar no computador
1. Abra a pasta no VS Code.
2. Rode um servidor local (ex.: Live Server) e abra no navegador.
3. Para PDF: clique em **Imprimir / PDF** e escolha “Salvar como PDF”.

## Publicar no GitHub Pages
- Suba os arquivos para um repositório.
- Settings > Pages > Deploy from branch > main > /root.
